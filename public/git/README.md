# Тренажёр команд Git (внешнее под-приложение)

Модуль **M7 «CI/CD и quality gates»** ссылается на интерактивный тренажёр команд Git —
самодостаточный одностраничный HTML в этой папке (`public/git/index.html`).

Схема та же, что и у учебника Go в `public/go/`: тяжёлый готовый контент подключается файлом
на месте, тренажёр остаётся без зависимостей. Прогресс тренажёра хранится в localStorage браузера.
