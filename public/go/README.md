# Учебник по Go (внешний проект)

Модуль **M15 «Go для QA»** ссылается на отдельный проект — веб-учебник по Go — и не дублирует
его содержимое.

## Как подключить

Положите одностраничный HTML вашего учебника по Go в эту папку под именем:

    public/go/index.html

После этого ссылка «веб-учебник по Go» в описании модуля M15 откроет его.

Схема такая же, как с `vendor/` для sql.js: тренажёр остаётся без зависимостей, а тяжёлый
готовый контент подключается файлом на месте. Так учебник и тренажёр развиваются независимо,
и содержимое учебника не переписывается.

Если файла ещё нет, ссылка приведёт на 404 — это ожидаемо до подключения; сами QA-задачи модуля
M15 работают независимо от учебника.
